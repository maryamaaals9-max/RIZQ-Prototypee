# RIZQ — Visual Upgrade

A visual upgrade of the original RIZQ Streamlit prototype. Existing workflow and simulated-data disclosures are preserved.

## Deploy
Upload `app.py` and `requirements.txt` to the root of your GitHub repository. `assets/` includes reusable illustrations, but images are also embedded in the Python file for reliable Streamlit Cloud rendering.

Streamlit Cloud: repository `RIZQ-Prototype`, branch `main`, main file `app.py`.

All building data, financial flows, workers, scores and impact calculations are synthetic demonstrations.
